# Migration history

This table summarizes the purpose of each SQL migration. See the
[PostgreSQL persistence guide](../../../../docs/postgres-persistence.md) for
migration execution and schema details.

| Migration                                | Summary                                                                                                                                                                                                                                                                                                 |
|------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `001_initial.sql`                        | Creates the base tables and indexes in the configured schema.                                                                                                                                                                                                                                           |
| `002_run-cancellation-status.sql`        | Extends the `runs` status constraint for cancellation and timeout states.                                                                                                                                                                                                                               |
| `003-run-policy-metadata.sql`            | Adds per-pipeline run-policy metadata and timeout values, plus request, correlation, and event metadata. `runs.allow_overlap` records the admission policy for each submitted run: `false` (default) waits while another run for the pipeline is active; `true` permits claiming alongside active runs. |
| `004-run-queue-sequence.sql`             | Adds a monotonic FIFO queue sequence and updates the queue index.                                                                                                                                                                                                                                       |
| `005-run-lifecycle-diagnostics.sql`      | Adds durable lease-loss, recovery-reason, and terminal-event diagnostics.                                                                                                                                                                                                                               |
| `006-run-spark-reattach.sql`             | Records legacy session and operation fields for schema-history compatibility; the current runtime does not use Spark operation reattachment.                                                                                                                                                            |
| `007-run-refresh-modes.sql`              | Adds selected refresh target names and extends the run-mode constraint for dry runs and selected refreshes.                                                                                                                                                                                             |
| `008-trigger-foundation.sql`             | Adds trigger definitions, normalized events and deduplication, routing decisions, and delivery attempts.                                                                                                                                                                                                |
| `009-trigger-routing-outcomes.sql`       | Adds `DEBOUNCED` and `FAILED` outcomes to the trigger-routing outcome constraint.                                                                                                                                                                                                                       |
| `010-trigger-dead-letters.sql`           | Adds recoverable trigger dead letters.                                                                                                                                                                                                                                                                  |
| `011-yaml-trigger-ownership.sql`         | Adds the `managed_by_yaml` ownership marker and index for direct pipeline-YAML trigger reconciliation. Removing a YAML trigger disables it without deleting event, delivery, or dead-letter history.                                                                                                    |
| `012-trigger-active-state.sql`           | Adds the non-null `active` flag to trigger definitions, defaulting to `true`.                                                                                                                                                                                                                           |
| `013-run-remote-cli.sql`                 | Retains an already-versioned migration that the current execution path does not use.                                                                                                                                                                                                                    |
| `014-run-local-cli.sql`                  | Adds local CLI identity, process state, run directory, start time, log offsets, the `UNKNOWN` run status, and its recovery index.                                                                                                                                                                       |
| `015-run-recovery-index.sql`             | Adds an index for active runs without a local CLI identity, including rows whose lease record was lost.                                                                                                                                                                                                 |
| `016-unknown-run-node-outcome.sql`       | Allows `UNKNOWN` node states so active node projections on an unverified run are not persisted as confirmed failures.                                                                                                                                                                                   |
| `017-run-success-dependencies.sql`       | Adds durable successful-run handoffs.                                                                                                                                                                                                                                                                   |
| `018-optional-pipeline-run-timeouts.sql` | Makes legacy pipeline and run timeout columns nullable with no default; clears the former global default from pipeline rows and queued or active runs while retaining terminal run values. Current pipeline timeout values come only from the optional YAML `timeout_seconds` setting.                  |
| `019-pipeline-source-snapshots.sql`      | Stores immutable parsed source snapshots for run recovery.                                                                                                                                                                                                                                              |
